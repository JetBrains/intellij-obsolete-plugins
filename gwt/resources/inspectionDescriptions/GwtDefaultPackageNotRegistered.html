Reports a GWT module descriptor that doesn't register default client or public folders, but registers custom source or public folders.

GWT implicitly treats the client folder as a client-side source path only if there are no source and super-source tags in the gwt.xml file. So, if the client folder exists, but it is not registered in the gwt.xml file, and gwt.xml declares custom source or super-source tags, most probably this indicates a mistake.

Similarly, if gwt.xml declares custom public folders, but doesn't register an existing folder with the default name, this may also indicate a mistake.

The quick-fix adds an explicit registration for the default folder to the gwt.xml file.
