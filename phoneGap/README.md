# Cordova

Cordova, PhoneGap, and Ionic support.

This plugin is obsolete.

## Build

The build needs JDK 25 and network access to Maven Central and the IntelliJ repositories.

```
./gradlew buildPlugin
./gradlew test
```

The plugin archive appears in `build/distributions/`.
