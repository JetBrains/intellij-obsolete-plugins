# AI Debugger

<!-- Plugin description -->

## Overview
The AI Agents Debugger plugin gives you instant visibility into LangGraph / LangChain / Koog agents —
right inside your IDE and with zero setup.

## Key Features
* **Live Agent Monitoring**: Observe your agents executing tasks in real time and explore detailed step-by-step traces to quickly identify and resolve issues.
* **Zero-Config**: Start collecting trace data immediately — no extra configuration needed.
* **Integrated Workflow**: Tracing activates from the familiar Run interface in your JetBrains IDE, with a dedicated tool window that presents a traces right inside the development environment.

## Getting Started
1. Install the plugin from the JetBrains Marketplace.
2. Open any Python project with LangGraph / LangChain / Koog in your IDE.
    1. For LangGraph / LangChain: make sure to open at least one source code file that includes a `langgraph` or `langchain` import — this helps the plugin detect that your project uses AI components.
    2. For Koog: ensure to use Koog version 0.5.2 or higher!
3. Start your agent with the Run command — you'll see the tool window appear automatically.
